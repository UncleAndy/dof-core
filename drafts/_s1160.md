### 11.60. Перенос v0.11 в C++, шаг 4: документ объявления и отпечаток линейки

**Два отпечатка, две разные вещи.** До v0.11 «отпечаток линейки» был отпечатком всего объявления. §3.4.2 разделяет: `digest()` — ключ одного **чтения** (§3.4.3), `ruler_digest()` — ключ **цикла**: тот же документ без `entities`, `freeze` и `verdicts`. Порт, воспроизводивший только первый, проходил бы все исторические проверки и всё равно расходился бы в том, **какие числа с какими можно сравнивать**.

Реализация — не второй писатель, а тот же: писатель разрезан на `entities_json()`, `canonical_tail(with_verdicts)` и `canonical_text()`; линейка — `canonical_tail(false)`. Ключи сохраняют канонический порядок, поэтому текст линейки есть ровно документ без трёх блоков. Полный текст остался байт-в-байт прежним — это подтверждают замороженные отпечатки v0.7.

**Замороженный якорь добавлен в порт.** `kExpectedRulerDigestV011 = 81948b8b…` и проверка «отпечаток линейки равен замороженному значению байт-в-байт». Раньше в порте слово «ruler» означало отпечаток объявления; теперь у обоих своё имя.

**Оговорка §11.58 закрыта — сверка с эталоном.** Собраны значения эталонного порта (Go) и этого порта для одной и той же фикстуры, с объявленными длительностями `t_m = 100`, `t_v = 50` у линзы `variety`:

| величина | Go (эталон) | C++ | |
| --- | --- | --- | --- |
| отпечаток объявления | `5126fd99…` | `5126fd99…` | совпал |
| отпечаток линейки | `81948b8b…` | `81948b8b…` | совпал |
| фрагмент `freeze` с длительностями | `{"measurement_durations":{"variety":{"t_m":"100.000000","t_v":"50.000000"}},"tau_mks":"4000000.000000"}` | тот же текст | совпал байт-в-байт |
| отпечаток объявления с длительностями | `28241d2f…` | `28241d2f…` | совпал |
| отпечаток линейки с длительностями | `81948b8b…` | `81948b8b…` | **не сдвинулся** — и не должен |

Последняя строка — не совпадение, а содержание правила: длительности лежат в `freeze`, а `freeze` из текста линейки исключён. Отсюда же следствие для §3.4.1: объявленные длительности — содержание линейки **чтения** (другое чтение не вправе переопределить, сколько длится измерение), но не ключ цикла.

**`dump` как инструмент диффа.** Вывод `dump` теперь печатает по отдельности отпечаток объявления, отпечаток линейки, отпечаток наблюдения, фрагмент `freeze` с длительностями и оба отпечатка с длительностями. Расхождение между портами по этому полю становится `diff`, а не загадкой.

**Прогоны:** `cpp` 117/0 (проверка отпечатка линейки добавлена), `cpp-v08` 36/0, `cpp-v091` 15/0, `cpp-v06` 58/4 (исторические).
